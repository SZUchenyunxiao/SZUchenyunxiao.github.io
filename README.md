# Chen Yunxiao — 3D Reconstruction Portfolio

Personal portfolio focused on 3D reconstruction, computer vision, point-cloud processing, 3D Gaussian Splatting, and spatial intelligence.

**Live site:** [szucyx.github.io](https://szucyx.github.io/)

## Tech stack

React · TypeScript · Vite · Three.js · React Three Fiber · Cloudflare Workers · D1

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site is deployed to GitHub Pages through GitHub Actions.
